I found information about the Splice MCP server. Here's what I found:

## Splice MCP Server Overview

The Splice remote MCP server is a hosted Model Context Protocol endpoint at https://mcp.splice.com/mcp, so AI assistants can connect to it without installing or running anything locally.

## Functionality

The Splice MCP Server lets you search Splice's sample catalog, build stacks, and download sounds directly inside AI tools like Claude — without opening the Splice app or switching tabs. Just describe what you're looking for in plain language, and the AI handles the rest.

Features include: searching by feel with natural language descriptions, building full multi-layer arrangements, building stacks from a sample as a starting point, editing stacks, sharing stacks via public links, and downloading samples using your credits.

## Setup Instructions

Add a new MCP server using the URL: https://mcp.splice.com/mcp, and the first time you use a Splice tool, log in through your browser. Any AI tool that supports HTTP-based MCP servers can connect using the same URL, and once connected, you can just talk to your AI assistant naturally with no special commands needed.

## Usage Limits

Splice documents a cap of 100 sample downloads per rolling 24-hour period through the MCP server, separate from your monthly credit allowance.

The whole server is beta—Splice labels the MCP server and the Describe a Sound feature behind it as beta.

No. Splice has no public HTTP API. The MCP server at mcp.splice.com/mcp is the only supported developer integration, and it's labelled beta.

What exists:

  • MCP server (official, beta). Browser OAuth login, session persists until it expires. Search, stacks, share links, and downloads capped at 100 per rolling 24 hours on top of your credits. No API keys, no developer docs beyond the setup article.
  • Unofficial GraphQL. The Splice desktop app talks to an internal GraphQL endpoint. It's undocumented, unsupported, and can change or be blocked at any time, so I wouldn't build on it.
  • Not Splice. Search results for "Splice API" mostly hit the unrelated Canton Network "Splice" blockchain and Splice CAD; ignore those.

Practical implication for mate: the MCP adapter is the right path, and the token you copied from the Keychain will expire. Since the server uses standard browser OAuth, giving mate its own OAuth flow through the MCP SDK's OAuthClientProvider is the durable fix, as discussed earlier.
